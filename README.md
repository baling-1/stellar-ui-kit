# stellar-ui-kit

**Live demo:** https://stellar-ui-kit-lyart.vercel.app


Ready-made React components for building apps on Stellar.

## Components

- **AddressDisplay**: shortens a Stellar address and copies the full address on click

## Coming soon

- WalletConnectButton (Freighter)
- AccountBalance
- TransactionStatus

## Usage

```tsx
import { AddressDisplay } from './components/AddressDisplay'

<AddressDisplay address="GBZXN7PIRZGNMHGA7MUUUF4GWPY5AYPV6LY4UV2GL6VJGIQRXFDNMADI" />
```

## Run locally

```
git clone https://github.com/baling-1/stellar-ui-kit.git
cd stellar-ui-kit
npm install --legacy-peer-deps
npm run dev
```
